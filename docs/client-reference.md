## 1) 사용 방법

- 고객이 준 링크를 그대로 붙여 넣고, 링크마다 적용 이유를 함께 작성한다.
- 구현 시 우선순위는 `must > should > avoid` 순서로 반영한다.
- 참고 링크끼리 충돌하면 "전환 효율 + 가독성 + 접근성" 기준으로 결정한다.

## 7) 구현 가드레일 (AI 체크)

- 링크를 그대로 복제하지 않고 브랜드 톤에 맞게 재해석한다.
- 색상/타이포/간격 시스템을 토큰 기반으로 통일한다.
- 모바일 우선으로 레이아웃을 확인하고 tablet/laptop/desktop으로 확장한다.
- 전환 요소(CTA, 폼, 신뢰요소)를 화면 상단에서 빠르게 인지 가능하게 배치한다.
